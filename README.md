Github CheatSheet:
git checkout -b 'naam' 'bron(dev)'
- voor branch te maken, 'naam' vervangen met git snippit 3de keuze

git checkout dev
- switched naar dev of kies ander branch

git branch
- overview van open branches

git branch --all
- vraag alle branches op

git fetch --all
- check voor updates van alle 'origin' branches

git pull --all
- pulled alles lokaal

git status

b1 mergen naar b2(dev):
- git checkout b1
- git pull origin b2
- 'resolve issues and commit + push'
- git checkout b2
- git merge b1
